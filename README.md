# Между делами

Журнал фокуса: отмечай, чем занята, смотри, как прошёл день, и записывай, как ты.

- Кольцо фокуса с целью на день (по умолчанию 10 часов)
- Дела: Работа (Собор, Da.school, Академия талантов), Рутина, Чтение, Итальянский, Спорт, Ходьба и свои
- Итальянский можно вести параллельно с рутиной
- Шкала дня цветными полосами — сегодня и два предыдущих дня рядом
- Записи о состоянии свободным текстом, хроника дня
- Экспорт в .txt, резервная копия и восстановление (.json)
- Устанавливается на главный экран, работает без интернета

Все данные хранятся только в браузере на твоём устройстве.

## Публикация на GitHub Pages

1. Создай репозиторий (или открой существующий) на github.com.
2. **Add file → Upload files**, перетащи все файлы из этой папки, **Commit changes**.
3. **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

Обновление: загрузи новые `index.html` и `sw.js` поверх старых.
